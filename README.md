# Habyx Dashboard

Flask dashboard prototype for a habit-tracking app.

## Setup

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Edit `user.txt` to change the default dashboard data. Users can also open
`/login`, enter their own details, and the dashboard will show the data they
gave during login.

Open the dashboard at:

```text
http://127.0.0.1:5000
```
